# claude-genmon

A [GenMon](https://docs.xfce.org/panel-plugins/xfce4-genmon-plugin/start) plugin
script that reports Claude Code usage (5-hour and 7-day utilization) from
`~/.claude/.credentials.json`.

## Install

```sh
cargo install --path .
```

This installs a `claude-genmon` executable (into `~/.cargo/bin` by default).
